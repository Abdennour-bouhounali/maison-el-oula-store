# 🌿 La Maison El Oula - Premium Natural Store

Welcome to the official repository of **La Maison El Oula**, a premium e-commerce platform dedicated to high-quality Algerian natural powders (Fruits, Vegetables, and Herbs).

## ✨ Key Features

- **🛍️ Elegant Storefront**: A minimalist, high-end shopping experience focused on product purity.
- **🌍 Multilingual Support**: Fully localized in **French**, **Arabic**, and **English**.
- **🛠️ Admin Dashboard**: Complete product management, order tracking, and sales analytics.
- **🛒 Advanced Cart System**: Real-time cart updates with persistent storage.
- **📸 Dynamic Image Management**: Organized product image folders and professional upload handling.
- **🚚 Order Tracking**: Live status updates for customers from "Pending" to "Delivered".

## 🚀 Tech Stack

- **Frontend**: React.js, Tailwind CSS, Framer Motion (Animations), Lucide React (Icons).
- **Backend**: Node.js, Express.js.
- **Database**: MongoDB with Mongoose.
- **Authentication**: JWT (JSON Web Tokens) with role-based access (Admin/User).
- **State Management**: React Context API.

## 📦 Installation & Setup

### 1. Clone the repository
```bash
git clone git@github.com:Abdennour-bouhounali/maison-el-oula-store.git
cd maison-el-oula-store
```

### 2. Backend Setup
```bash
cd server
npm install
# Create a .env file and add your MONGO_URI and JWT_SECRET
npm run dev
```

### 3. Frontend Setup
```bash
cd ..
npm install
npm run dev
```
